# Fonts

All open-licensed; each licence file sits next to its font. Use them freely in the videos (keep the licence files with
any font you copy into a project). In the web engine they are CSS families (`font-family: "Space Grotesk"`); in Python
`mv.common.font(name, size)`.

Carried over from aftermovie-studio (Anton, Bebas Neue, Archivo Narrow, Caveat, Inter, Noto Sans Georgian, Permanent
Marker, Playfair Display, Space Mono, Special Elite; their licence files were added here), plus Fraunces, Space Grotesk,
Syne, Instrument Serif, Unbounded, IBM Plex Mono and Noto Sans from google/fonts. These are raw material, not a style
menu: a video can bring its own open-licensed font (with its licence) when the concept needs it.
